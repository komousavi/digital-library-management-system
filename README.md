Digital Library Management System

A web-based digital library management system designed to organize, manage, search, and access digital books and documents.

Overview

The Digital Library Management System provides a centralized platform for managing digital resources and controlling user access to them.

The system allows users to search for digital resources, view resource details, and access available content based on their roles, permissions, and subscription status.

It also provides management tools for administrators and librarians to manage resources, users, subscriptions, categories, and system activity.

Main Features

- User Management: User registration, login, logout, and account management.
- Resource Management: Add, edit, organize, publish, and archive digital resources.
- Access Control: Manage user roles, permissions, and subscription-based access.
- Advanced Search: Search and filter resources by title, author, publisher, category, language, publication year, and file type.
- Online Reading: Preview and read supported digital formats, including PDF and EPUB.
- Download Management: Control resource downloads according to access permissions.
- Administration Dashboard: Manage users, resources, subscriptions, categories, and activity reports.

User Roles

The system supports different user roles, including:

- Administrator
- Librarian
- Registered User
- Guest
- Subscriber
- Special Researcher

Each role has specific permissions and access levels.
